# 오산대학교 전공·취업동아리 자료실

학생취업처에서 동아리 정산 서식과 간담회 자료를 배포하는 안내 페이지입니다. 별도 빌드 없이 index.html 하나로 동작하는 정적 페이지입니다.

## 폴더 구성

index.html 이 페이지 전체입니다. files 폴더에는 학생들이 내려받을 파일 세 개를 넣습니다.

## 파일 넣는 방법

구글 드라이브 폴더에서 아래 세 파일을 내려받아 files 폴더에 넣고 GitHub에 올립니다. 파일 이름은 아래와 글자 하나까지 똑같아야 합니다. 이름이 다르면 버튼을 눌러도 파일이 받아지지 않습니다.

영수증 붙임철&검수조서(전공).hwpx
영수증 붙임철&검수조서(취업).hwpx
2026학년도 2학기 간담회 자료.pptx

실제 파일 이름이나 확장자가 다르면, 파일 이름을 위와 같이 바꾸거나 index.html의 다운로드 버튼 세 줄(href와 download 값)을 실제 이름으로 수정하세요. 학생이 내려받을 때는 download에 적힌 이름이 그대로 쓰입니다.

## GitHub에 올리고 공개하기

새 저장소를 만든 뒤 이 폴더 안의 내용을 모두 올립니다. 저장소의 Settings, Pages에서 Branch를 main, 폴더를 root로 선택하고 저장하면 몇 분 뒤 https://계정명.github.io/저장소명/ 주소로 공개됩니다.

## 내용 수정

제출 기한, 금액 기준, 사용 금지 문구는 모두 index.html 안에 들어 있습니다. 학기가 바뀌면 상단의 학기 표기와 간담회 자료 파일 이름을 함께 고치세요.
