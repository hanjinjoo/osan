# 오산대학교 전공·취업동아리 자료실

동아리 서류 안내 및 다운로드 페이지: https://hanjinjoo.github.io/osan/

정적 GitHub Pages 사이트로 빌드 도구 없이 `index.html`로 동작합니다.

## 최신 정산서류 6종 (2026학년도 2학기)

정산 서식은 **전공동아리 / 취업동아리**별로 각각 3종이며, 학교에서 확정한 HWP 원본을 그대로 배포합니다.

| 구분 | [서식 05호] | [서식 06호] | [서식 07호] |
|---|---|---|---|
| 전공 | 법인카드 사용 승인요청서(전공) | 영수증 붙임 철(전공) | 검수 조서(전공) |
| 취업 | 법인카드 사용 승인요청서(취업) | 영수증 붙임 철(취업) | 검수 조서(취업) |

모든 파일의 원본 파일명은 `files/` 디렉터리에서 그대로 유지합니다. 사이트는 전공/취업 탭 전환 시 같은 유형의 서식 3종만 표시합니다.

법인카드 사용 승인요청서는 오산·수원 외 지역에서 사용하거나 학교 휴일 사용 기준에 해당할 때 카드 사용 전에 제출하는 조건부 서류입니다.

## 파일 및 기존 자료 보존

- `files/[서식5호] 법인카드 사용 승인요청서(전공).hwp`
- `files/[서식5호] 법인카드 사용 승인요청서(취업).hwp`
- `files/[서식6호] 영수증 붙임 철(전공).hwp`
- `files/[서식6호] 영수증 붙임 철(취업).hwp`
- `files/[서식7호] 검수 조서(전공).hwp`
- `files/[서식7호] 검수 조서(취업).hwp`

기존 간담회 PPTX와 구형 통합 HWPX 자료는 자동 삭제하지 않습니다. 다만 구형 HWPX는 최신 정산서류 다운로드 목록에서는 숨깁니다.

## 배포 전 필수 검증

```bash
python tests/check_settlement_forms.py
```

업로드한 원본 6개 파일의 SHA-256, HWP 헤더, 서식별 전공·취업 다운로드 링크 및 기존 PPTX/모니터링 링크를 검증합니다. 오류나 누락이 있으면 `main` 병합 및 운영 배포를 하지 마세요.
